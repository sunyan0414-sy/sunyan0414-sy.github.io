Privacy Policy

Last updated: October 12, 2026

Purpose

This is a personal backup utility using rclone to copy research files from Google Cloud Storage to the owner's Google Drive account. It is not offered as a public service.

Data Access and Use

The utility accesses Google Drive only with the owner's authorization for backup and file management. Files are transferred using rclone.

Data Storage and Security

Backup files are stored in the owner's Google Drive. OAuth credentials are stored locally by rclone, not on this website. This website does not collect or store Google Drive files.

Data Sharing

Research files and Google Drive data are not sold or intentionally shared with third parties. Google Cloud Storage and Google Drive are used to provide the backup functionality.

Access Revocation

The owner can revoke the application's access through Google Account security settings.
